# Workflow Map

## Material Requirement Lifecycle
```
Draft → Submitted → Under Review → Approved → In Progress → Completed
                              ↘ Rejected
```

## Purchase Order Lifecycle
```
Draft → Submitted → Approved → In Progress → Delivered → Completed
                           ↘ Rejected
```

## QC Lifecycle
```
Pending → Inspecting → Pass → Accepted into Inventory
                    ↘ Fail → Return to Vendor / Scrap
                    ↘ Conditional → Hold for Review
```

## Issue & Recovery Lifecycle
```
Issue Created → Approved → Issued to Vessel
                              ↓ Material Returned
                           Recovery Assessment
                              ↓
               Reuse / Repair / Scrap / Sell
```

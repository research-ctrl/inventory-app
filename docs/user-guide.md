# User Guide

## Getting Started
1. Log in at the SMLS sign-in page
2. Your dashboard shows an overview of activity in your modules
3. Use the left sidebar to navigate between modules

## Creating a Material Requirement
1. Go to Requirements → New Requirement
2. Fill in title, vessel, department, urgency, and item details
3. Click Submit to send for approval

## Tracking a Requirement
- Use the Requirements list to filter by status
- Click any requirement to see full history and workflow steps

## Using the AI Assistant
- Navigate to Chatbot
- Ask questions like "Where is PIN 12345?" or "What is the status of PO-2024-001?"

## Contact
For help, contact your system administrator.
